# 🐍 Student Grade & Average Calculator

A Python module to manage student academic records, calculate subject averages, and generate performance reports using Object-Oriented Programming (OOP).

---

## 📌 Features

- **Class & Object Architecture**: Encapsulates student data into reusable entities.
- **Constructor Scoping**: Stores student names and subject mark lists.
- **Average Calculation**: Computes aggregate scores.
- **Grade Assignment**: Evaluates performance into standard letter grades (`A+` to `F`).
- **Static Methods**: Includes utility helpers for portal notifications.

---

## 🚀 Execution

Run the script directly using Python:

```bash
python student_grades.py
```
